## Projektový vstup
Seznam stávajících projektů a lokálního draftu, připojit GitHub existujícím schváleným clone flow, připojit lokální složku odkazem nebo vytvořit nový prázdný lokální projekt. Lokální reference pouze ověří explicitní absolutní cestu a uloží ji; žádné automatické čtení obsahů, copy, git init ani změny originálu. Canvas graph pro local/empty žije v existující tabulce drafts keyed project ID, workspace=draft. Nepředstírat import codebase. Git projekty dál main/worktrees. Odpojení funguje pro všechny typy, data/zdroje zachová.
projects zůstává jediný registry; sourceKind/sourcePath doplní tabulka project_sources. Project settings revision/CAS: name (jediná autorita projects.name, ne duplicita v JSON), goal, platform (web/app/component), LLM provider/model, runtime budgetSeconds10..180. Povoleno bez secrets. GET /api/project-settings?project= -> {project:{id,name,url,branch,sourceKind,sourcePath},revision,settings:{goal,platform,provider,model,budgetSeconds}}. POST /api/project-settings exact {project,expected_revision,name,settings}. Draft také konfigurovatelný, jeho název uložen samostatně jako builtin metadata, ne druhý projekt.
POST /api/local-project {name,path,confirmed:true}: path absolutní existující adresář, resolved path viditelná, duplicate source neotevírá druhý registry (vrátí existující projekt). POST /api/empty-project {name,confirmed:true}. Nastavení/save a připojení musí odmítnout archiv a stale revizi. API role/Origin zůstává.

## LLM ovládání — skutečný, úzký první runtime
Pouze návrh bez nástrojů/zápisu přes Hermes, ne coding agent. Backend nemá přijímat shell, PID, credential nebo arbitrary URL. Model/provider explicitní, provider allowlist; model validovaný identifikátor. Nativní Hermes CLI s --safe-mode, --toolsets none, --max-turns 1, --run-budget, --reasoning low, --quiet a --query-file do aplikačního run adresáře. Bez automatického retriggeru, stop jen tracked vlastní strom. Interní timeout + vnější deadline, stdout omezený. Stop lokálního procesu není důkaz zastavení provider billing; UI to přizná. Před veřejným ovládáním ověřit reálný no-tools CLI seam a parent+child stop na neplacené fixture. Jeden aktivní run na aplikaci. Model output je návrh, ne DONE.
Před startem read-only preview contextu: project config, graph, NodeSpec aktuální vrstvy a wireframe z uložené kresby. Bounded JSON max50000 znaků; žádné soubory zdrojové složky ani .env. Digest váže scope/revize/model/policy. Start exact confirmed true + digest recheck. Po startu se otevře Canvas stejného projektu/scope. Výsledek a stop stav je zdrojovaný z runtime, nikoli odhad UI. Nedostupné CLI/provider -> explicitní error, žádná falešná odpověď.

## Wireframe bez duplikace
Jde o podsekci existujícího Kreslení, používá stejnou Excalidraw scénu a DrawingStore/CAS. Native x/y/width/height/barvy/text/frameId jsou jediná geometrická autorita. customData.oporaWireframe = {version:1,role:'block'|'element',component:string,template?:string,notes:string,action:string,behavior:string,animation:{preset:'none'|'fade'|'slide'|'scale',durationMs:number,delayMs:number},parallax:{enabled:boolean,speed:number}}. Metadata nesmějí kopírovat geometrii/barvy ani rodiče. Label z frame.name/text/bound text. Native frameId určuje kontejnery; sloupcová šablona je výchozí rozložení, ne constraint po ručním přesunu.
Bloky: prázdná sekce, dva/tři sloupce, hero/CTA. Elementy: nadpis/text/tlačítko/input/obrazový placeholder/karta/navigace. Vkládání, přesun/resize native, barvy/poznámky/action/behavior/presety animace a parallax editovatelné. Nevykonávat arbitrary JS z action/notes. Malý bezpečný náhled může přehrát jen podporované presety/scroll parallax, nesmí se tvářit jako hotový web builder.
GET /api/wireframe-context?project=&workspace=&layer= -> {project,workspace,layer,drawingRevision,blocks:[],elements:[],annotations:[],source}. Pouze uložená kresba. Native geometry + metadata projekce v backend/wireframe_context.py je jediný LLM-exportní mapper. Export UI až po save, nesmí tvrdit, že zahrnul neuložené změny. Projekce typů do LLM musí být citovatelná na scene IDs/revision a nezahazovat významové vazby.
