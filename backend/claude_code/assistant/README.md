Asistent: chat s Claude Code spuštěným aplikací pod předplatným uživatele (kontrakt `docs/asistent.md`, fáze 1 jen čte a radí). `manager.py` drží registr session (`registry.py`, `assistant/sessions.json`), jeden proces `claude -p` se stream-json na session (`session_process.py`, příkaz a prostředí bez `ANTHROPIC_API_KEY` v `command.py`) a buffer posledních 2000 událostí (`event_log.py`); limity 3 procesů, 15 min nečinnosti a 30 min tahu hlídá `watchdog.py`. `stream.py` je čistá funkce řádek CLI → události aplikace, `context.py` ověřuje kontext plátna a `transcript.py` čte historii z přepisu `~/.claude/projects/*/<id>.jsonl`. `fake_cli.py` je falešné CLI pro testy; skutečný `claude` testy nikdy nespouští.
