Asistent: chat s Claude Code spuštěným aplikací pod předplatným uživatele (kontrakt `docs/asistent.md`; čte a radí, na plátno zapisuje jen se schválením člověka, §5.1). `manager.py` drží registr session (`registry.py`, `assistant/sessions.json`), jeden proces `claude -p` se stream-json na session (`session_process.py`, příkaz a prostředí bez `ANTHROPIC_API_KEY` v `command.py`) a buffer posledních 2000 událostí (`event_log.py`); limity 3 procesů, 15 min nečinnosti a 30 min tahu hlídá `watchdog.py`. `stream.py` je čistá funkce řádek CLI → události aplikace, `context.py` ověřuje kontext plátna a `transcript.py` čte historii z přepisu `~/.claude/projects/*/<id>.jsonl`. `rlm_rank.py` řadí oddíly plátna k dotazu jedním voláním Jev (`docs/asistent.md` §13.3); klienta dostává injektovaného. Schválení (§5.1): `approvals.py` je čistá logika dotazu `can_use_tool` (auto-deny vše kromě `python …opora_write.py <cesta> …`, rozparsovaný cíl, `control_response`; bez dotazu pustí čtecí Bash a `Write` `*.json` do 2 MiB do adresáře konceptů session, `--json-file` přijme jen odtud a souhrn dělá z obsahu souboru, u `/api/canvas-plan` počty dávky; `docs/davka-planu.md` §2), `approval_book.py` eviduje čekající a rozhodnuté žádosti; `manager.py` při spuštění procesu založí `<data>/assistant-drafts/<sessionId>/` (env `OPORA_DRAFTS_DIR`, `draftsDir` v `<opora_context>`, smaže ho `close`), před povolením `--json-file` ověří otisk konceptu, po startu procesu pošle `initialize`, dotazy obslouží (`approval`, `approval_resolved`, stav `waiting_approval`), `decide` / `decide_approval` přijmou rozhodnutí a `sweep` po 10 min zamítne. `fake_cli.py` je falešné CLI pro testy (scénáře `WRITE`, `EDIT`, `DRAFT`, `ESCAPE`); skutečný `claude` testy nikdy nespouští.
