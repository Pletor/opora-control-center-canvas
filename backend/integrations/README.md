Platforma: git I/O (gitio), Windows job objekty pro ohraničené procesy (windows_job), identita buildu (build_identity), klient paměti OpenViking na loopbacku (openviking_client).

`github_review_reader` načítá pouze pozorování PR z pevného `api.github.com`: identitu repozitáře, přesné SHA, review s ověřeným oprávněním autora a kontroly. Repozitář dodává doména z konfigurace projektu, nikoli klientská URL. `github_review_transport` přijímá serverový `OPORA_GITHUB_TOKEN` (alternativně `GH_TOKEN`, `GITHUB_TOKEN`); bez něj zkusí veřejná data. Token se neukládá do pozorování. HTTP přesměrování jsou zakázána, odpověď má nejvýše 2 MiB, kolekce nejvýše 10 stránek po 100 položkách a celé pozorování nejvýše 80 požadavků s časovým rozpočtem 60 s. Odkazy pro stránkování se nikdy nenásledují; cesty generuje klient. Neúplná či změněná data pozorování odmítnou. Chybějící oprávnění review je `unknown`, nikdy schválení. Výsledek není oprávněním k merge ani verdiktem ověření implementace; politika patří doméně OporaHubu. Normalizaci polí drží `github_review_normalize`, testy používají vložený transport bez sítě.

`openviking_client` posílá jen `X-API-Key`: server v režimu `api_key` odvozuje identitu z klíče a hlavičky `X-OpenViking-*` odmítá. `with_api_key` vyrobí klienta jedné role, `admin_*` metody rozdají rolím klíče. Hlavičky identity zapíná až `trusted_identity=True` pro nasazení `auth_mode: trusted`.

`git_read` čte historii gitu pro párování commitů se zadáním: revize, předky, seznam posledních commitů, trailery a změněné cesty, přejmenování souboru a SHA obsahu. Jen čtení, vše přes `gitio.git`.

`mirror_client` volá Zrcadlo (BioCortexAI, docs/zrcadlo.md) jen na `127.0.0.1`/`localhost`, bez proxy a přesměrování, s timeoutem 2 s; vypnuto, porucha nebo neplatná odpověď = `None`. Zapíná ho `[mirror]` v `opora.local.toml` přes `OPORA_MIRROR_URL` a `OPORA_MIRROR_PROJECTS`.
