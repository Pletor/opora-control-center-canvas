Krok 1, úvodní nastavení: připojení repozitáře nebo složky, založení projektu, nastavení a metadata (project_hub.py); tabulky project_sources, project_settings, project_profile, builtin_project_metadata.

Nastavení projektu (`/api/project-settings`) má klíče `goal`, `platform`, `architecture` (`""`, `monolith`, `modular`, `microservices`, `serverless`), `tenancy` (`""`, `single`, `multi`) a `site` (nastavení a design webu: `seo`, `legal`, `email`, `design`; tvar, stropy a odmítnutí tajemství v `backend/canvas/site_settings.py`, leží jen v `project.json`, nevyplněné pole je `""`); `""` = nenastaveno (docs/suplik-a-profil.md). Profil leží ve vlastní tabulce `project_profile`, revizi nese dál `project_settings`; projekt bez řádku profilu (uložený před profilem) se čte s `""`, neznámá uložená hodnota taky. Zápis vyžaduje všech pět klíčů a `expected_revision`; neplatná hodnota i kolize revizí vrací českou chybu (409).
