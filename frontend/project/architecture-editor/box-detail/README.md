# Detail boxu (plátno 2)

Pravý sloupec plátna 2 po kliku na box layoutu (`docs/navrhy/2026-11-10-platno-2.md`, Verze 3 „Detail boxu“ a „Stavy boxu“). Skládá ho `page-editor/components/PageEditor.tsx`; dílek nic neukládá a každou změnu sekce hlásí `onChange(patch)` (rodič z ní udělá nový layout `patchSection` a uloží přes `onLayout` se zámkem `patchLock`).

- **Název, role, záměr**: uloží se při opuštění pole (prázdný název se vrátí). Záměr = funkčnost boxu, nejvýš 600 znaků (`INTENT_MAX`, backend `SECTION_INTENT_MAX`, Verze 6). Struktura: jde měnit i na Git mainu. Popis vzhledu `look` (ze skenu) ukazuje pohled Design plátna, Detail ho zatím needituje.
- **Stav**: Rozpracováno (`draft`, i chybějící `status`) → Schválit; Návrh (`proposed`, od agenta nebo skenu) → **Přijmout** (= `approved`) / **Zahodit** (box pryč i s vnořenými, `onDiscard`); Schváleno → Vrátit do rozpracování. `source` (kdo box zapsal) jen ukazuje, zapisuje ho server.
- **Skica** (`components/BoxSketch.tsx`): náhled uložené kresby (`logic/use-sketch-preview.ts`: `GET /api/drawing` vrstvy `box/<pageId>/<sectionId>`, SVG přes Excalidraw načtený až když kresba něco má) a **Kreslit skicu** = velké okno (obyčejná vrstva, ne `<dialog>`, kvůli nabídkám Excalidraw) s existujícím `editor/canvas/drawing/` `DrawingWorkspace` (líně načtený). Ukládá samo kreslení (`/api/drawing`, revize, obrázky); po uložení rodič obnoví značky (`onSketchSaved`). V zanořeném pohledu boxu (`page-editor/box-focus/`) se skica otevřeného boxu kreslí na ploše a blok Skica se skryje (`sketch={false}`).
- **Inspirace** (`components/BoxInspiration.tsx`): 0–6 obrázků PNG/JPEG/WebP/GIF do 10 MB (Ctrl+V do zóny, přetažení, výběr souboru), nahrané `uploadImage` → `POST /api/drawing-file` (id = SHA-1 obsahu), náhledy z `/api/drawing-files` (`logic/use-inspiration-files.ts`), klik zvětší; odkaz na web (jen http/https) a poznámka ≤ 200. Ukládá se jako `section.inspiration {files?, url?, note?}`; prázdné vynechá `pageSiteForSave`. Stejným zápisem přidá převzetí Designu ze skenu výřez boxu (`page-editor/plan-scan/`); první obrázek inspirace kreslí pohled Design přes celý box.
- **Prvky logiky boxu**: druh, název, stav; klik otevře Detail prvku (s odkladem 250 ms, aby se stihl dvojklik), dvojklik plátno logiky prvku (`onOpenLogic` z kontextu `project-flows`).
- **Zámky**: `layoutLock` (struktura) vypne název, roli, záměr a stav; `contentLock` (obsah, Git main, kompletní stránka) vypne skicu a inspiraci a ukáže větu proč.

Soubory: `components/BoxDetail.tsx`, `components/BoxSketch.tsx`, `components/BoxInspiration.tsx`, `logic/box-detail.ts` (test vedle: stavy, `patchSection`, `patchLock`, `inspirationRejects`, `addInspirationFiles`, `removeInspirationFile`, `inspirationUrlError`, `boxSketchLayer`), `logic/use-sketch-preview.ts`, `logic/use-inspiration-files.ts`, `styles/box-detail.css` (předpona `box-detail`).
