# Sken webu (plátno 2)

Skenovat web z hlavičky plátna (`docs/navrhy/2026-11-10-platno-2.md`, Verze 3 „Sken přes REA“ a Verze 6 „Sken převezme design, layout i tok dat“). Výzkumník srdce projde web a navrhne layout stránky, design webu a prvky logiky s tokem dat; nic se nepřepíše, dokud člověk návrh (nebo jeho část) nepřevezme.

- `components/ScanDialog.tsx`: okno s adresou (http/https) a nepovinnou poznámkou „co z webu převzít“. Spustit předá obojí `PageEditor` a okno zavře.
- `logic/use-page-scan.ts`: `POST /api/page-plan/scan` → `scanId`, pak `GET /api/page-plan/scan/{scanId}` každé 3 s, nejvýš 10 minut. **Zrušit** jen přestane čekat (kontrakt nemá endpoint pro zastavení). **Obnova**: po otevření stránky `GET /api/page-plan/scan/latest` (404 i chyba = nic) ukáže poslední hotový nepřevzatý návrh, aby se odchodem ze stránky neztratil. **Zahodit** volá `POST /api/page-plan/scan/{scanId}/discard`; selhání nechá panel s důvodem. Změna stránky běh zahodí.
- `logic/page-scan.ts` (test vedle): `startScan`, `readScan`, `readLatestScan`, `discardScan`, `captureUrl` / `fetchCapture` (`GET /api/page-plan/scan/{scanId}/capture/{name}`), `adoptScanLayout` (`GET /api/page-plan` pro otisk a `POST /api/page-plan` se `scanId`) a tolerantní `normalizeScan`: neznámý stav = chyba s větou; sekce s platným unikátním id, neznámá role = Vlastní, chybějící název = popisek role, `intent` do 600 a `look` do 300 znaků, `selector` jen pro náhled (`layoutOfProposal` ho před zápisem odebere), box v mezích mřížky a usazený bez překryvu (`settleLayout`, náhled i převzetí stejně), rodič jen v návrhu bez cyklu, vždy `status: "proposed"`, nejvýš 40; prvky logiky jen s druhem z palety logiky, box jen ze sekcí návrhu (jinak Celá stránka), `flow` (`inputs`, `steps`, `outputs`, `conditions`, `dataTo`, každý nejvýš 8 × 160 znaků); `design` jako objekt tokenů; `captures` jen s bezpečnými jmény souborů a výřezy jen sekcí návrhu; `notes`.
- `logic/adopt-scan.ts` (test vedle): pořadí a věty převzetí po částech. Selhání jedné části nezahodí ostatní; výsledek `{part, ok, text}` řekne, co se převzalo a co ne.
  - **Layout**: `POST /api/page-plan` se `scanId` (bez výřezů: inspirace ve stejném zápisu by boxu dala `source: "human"`).
  - **Design**: výřez každého boxu stáhne a nahraje jako obrázek kresby (stejně jako ruční inspirace v Detailu boxu) a až po layoutu ho samostatným zápisem grafu přidá do `inspiration.files` boxu se stejným id (i když se layout nepřevzal). Snímek celé stránky zůstane jen v panelu: stránka nemá vlastní inspiraci (mechanismus neexistuje). Tokeny `design` se slijí do Design systému projektu.
  - **Logika a tok dat**: prvky jedním plánem `/api/canvas-plan`, pak každému prvku s `flow` plátno logiky (`POST /api/library/project-flows`) a jeho první verze (draft `/api/flow/workflows/{id}/versions`, jako ruční uložení). Plátno, které už verzi má, se nepřepíše.
  - Na mainu (zámek obsahu) se výřezy a logika nepřevezmou a věta řekne proč; Layout a tokeny ano.
- `logic/scan-adopt-deps.ts`: zápisy převzetí nad úložištěm editoru (volá jen `ArchitectureEditor`): každý zápis grafu si znovu načte pohled a píše nad jeho digestem; id uzlů prvků z `refs` plánu (`logic-<pořadí>`), plátna toku až po zápisu plánu.
- `logic/scan-flow.ts` (test vedle): `scanFlowGraph(flow)` graf první verze toku jen z existujících typů katalogu toků dat: vstupy (sloupec) → podmínky `flow.if` v řetězu (pokračuje `true`) → kroky `custom.step` v řetězu → výstupy a pod nimi cíle dat (`dataTo`) jako `custom.step`. Text bez typu je krok na míru (vrstva `neutral`, `params.title`), id uzlu čitelné (`vstup-1`, `krok-2`, `podminka-1`, `vystup-1`, `data-1`), text i v poznámce na kartě. `flowSize` pro náhled.
- `logic/scan-design.ts` (test vedle): `mergeDesignTokens(uložené, návrh)` slije tokeny podle jména v rodině (barva uložená po tématech dostane hodnotu jen v prvním tématu), písma podle klíče, styly podle skupiny a jména; nic nemaže, témata a soubory písem zůstanou. Vrací i seznam změn staré → nové.
- `components/ScanPanel.tsx`: panel vedle plátna (`page-editor__stage--scan`): průběh se Zrušit, chyba, návrh po částech, nebo po převzetí výsledek každé části (✓ / ✕ s větou) se Zavřít (a Zahodit návrh, když se layout nepřevzal: server sken označí jako převzatý jen zápisem layoutu).
- `components/ScanParts.tsx`: tři části se zaškrtávátky (výchozí vše): **Layout** (náhled `LayoutCanvas preview` s funkčností boxů), **Design** (snímek stránky, výřezy boxů, změny tokenů staré → nové), **Logika a tok dat** (prvky s boxem a počtem kroků toku); poznámky skenu; **Převzít** hlásí zaškrtnuté části `onAdopt(parts)`, **Zahodit** `onDiscard`.
- `styles/plan-scan.css`, předpona `plan-scan`.
