# Karta Mapy architektury

Uzel React Flow pro Editor stránky. Oblast je přerušovaný jantarový rám s hlavičkou „OBLAST: …“, počtem sektorů (geometrické členství, `membersOf`) a „+ Sektor“. Vybraná oblast má tahadla na hranách a rozích (`NodeResizer`, 120–20 000 px); ustálený rozměr hlásí `actions.resizeArea`, plátno ho pošle rodiči a ten ho uloží jako `size` uzlu. Sektor / uzel je karta v barvě své vrstvy: ikona v rámečku, druh, název, účel, štítek „N uzlů“, menu ⋮ (Otevřít detail, Otevřít v Editoru), až tři potomci jako řádky a „+ Přidat komponentu“. Podstránka (`site.kind = "page"`, `summary.page`) je odkaz na svou stránku: čárkovaný rám, druh „Podstránka“, cesta pod názvem a místo přidání komponenty „Otevřít stránku →“ (`actions.openPage`); porty zůstávají kvůli navigačním vazbám. Porty vlevo (vstup) a vpravo (výstup) jsou barevné kroužky.

Karta dostává hotová data (`cardSummary`, `areaSectorLabel` z `../logic/canvas-model.ts`) a stabilní `actions`, které plátno směruje na aktuální callbacky rodiče. Nic neukládá.

Porty (2026-10-27): úchyty jsou `PortHandle` ze `shared/flow-ports` (oblast = `flow`, uzel / sektor = `next`); barvu dodává `--tone` přes `--port-fill`. `ArchitectureCanvas` vkládá `PortZoomVar` pro stálou velikost portů. Výstupní port uzlu / sektoru: klik (pod prahem pohybu) nebo Enter volá `actions.openPortMenu` – nabídka vazby (`port-menu/`); tah dál táhne vazbu.
