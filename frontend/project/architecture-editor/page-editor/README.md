# Editor stránky

Krok 3 kontraktu `docs/architektura-projektu.md`: rychlá infografika jedné stránky ve čtyřech sloupcích (grid).

1. **Levý panel (280 px)** – záložky *Strom projektu* (`project-tree/`) a *Knihovna prvků* (`ArchitectureCatalog`): rodiny Frontend, Backend, Databáze, Security, Testy, Cache, Cloud a infrastruktura (`logic/library-families.ts`) jako barevně orámované skupiny s počtem a sbalením, dlaždice po třech, hledání, přetažení na mapu i tlačítko „Vložit“.
2. **Mapa architektury** (`ArchitectureCanvas` + `map-card/`) – oblasti, sektory a uzly otevřeného rozsahu stránky. Barva karty podle `card.layer` (sektor bez vrstvy = frontend), porty vlevo/vpravo, vazby barvou zdroje se šipkou, `flow` přerušovaně; vazba `next` s `carries` má barvu druhu toku (token `--edge-carries-<druh>`, šipka literálem `CARRIES_COLORS`), událost čárkovaně, příkaz o 0,5 px silněji, druh v `ariaLabel` a háček `edge--carries-<druh>` (`logic/canvas-model.ts`, `edgeLook`). Po najetí na vazbu se u kurzoru ukáže popisek „zdroj → cíl“ a druh toku, případně „Neurčeno – nastavte v Detailu prvku → Vazby“ (`edge-hint/`). Dvojklik nebo „Otevřít detail ↗“ otevře Hierarchický editor. Podstránka otevřeného rozsahu zůstává na plátně, ale jako **odkaz na stránku** (`map-card--page`: čárkovaný rám, „Podstránka“, cesta, jediná akce „Otevřít stránku →“; dvojklik přepne rozsah). Porty a vazby má dál, takže navigační vazba (`carries: navigation`) z komponenty na podstránku zůstává vidět a jde ji táhnout; komponenty se do podstránky přidávají na jejím vlastním plátně.
   Nad plátnem: **pruh navigace domény** (`page-nav/`, stejné stránky a popisky jako NAVBAR Mapy domény, aktivní stránka zvýrazněná, klik přepne rozsah stejně jako Strom), **úsek cesty zákazníka** aktivní stránky a **pruh sekcí** s počtem komponent (`journey-slice/`). Aktivní stránka = nejbližší stránka otevřeného rozsahu (`activePageId`).
3. **Hierarchický editor komponenty** a 4. **Detail prvku (300 px)** – PageEditor je nevytváří; rodič `ArchitectureEditor` je složí (`component-structure/`, `element-detail/`) a předá jako sloty `structure` / `detail`. Sloupec se ukáže jen, když slot není `null`.

Šířku řeší CSS (`logic/page-layout.ts` skládá jen BEM varianty): pod 1400 px se mapa a struktura střídají přepínačem „Mapa / Struktura“, pod 1050 px vyjede detail zprava jako zásuvka.

Puštěná karta na mapě dosedne jako v Editoru: když přetáhne hranu své oblasti a je kam růst, oblast se za ní (už během tahu) natáhne a uloží se s ní; jinak se karta vtáhne do oblasti nebo vysune ven, aby nikdy nepřečnívala (`editor/canvas/area/logic/area-growth.ts`, rozměry karet ze změřeného `measured`).

Dílek nic neukládá: všechny změny (vložení, přesun, vazba, nový uzel / sektor / oblast, „+ Stránka“) hlásí callbackem rodiči. „+ Stránka“ v Stromu přepne na Mapu projektu dané domény – strukturu stránek mění jen ona. React Flow při přestavbě uzlů přenáší `measured`, jinak by se karty znovu měřily a vstupy ztrácely fokus. Pohled plátna se pamatuje v `localStorage` podle ID editoru a rozsahu.
