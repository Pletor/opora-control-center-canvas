# Studio (pohled na mapu domény)

Druhý pohled na mapu domény vedle **Stránky** (kontrakt `docs/architektura-pro-agenty.md` §7, etapa 9). Stejná data, jen ke čtení: nahoře cesty zákazníka jako dráhy se stavem posledního ověření, pod nimi tok domény podle `carries`. Přepínač **Stránky | Studio** je v hlavičce mapy (`domain-map/components/DomainViewSwitch.tsx`), stav drží `ArchitectureEditor` a zapisuje ho do adresy jako `domainView=studio` (výchozí Stránky, parametr chybí; čte `domainViewOf` v `logic/editor-route.ts`). Žádost o editor cesty (úsek cesty v Editoru stránky, Díry mapy) přepne Studio zpět na Stránky.

- `components/DomainStudio.tsx` skládá dílky: dráhy spočítá čistou funkcí `studioLanes` z `site.journeys` domény, stránek a `derivedJourneys` (odvození backendu §6, `lastRun` podle `docs/brana-cesty.md` §4); tok dostane hotový v `flows` (spočítá `ArchitectureEditor` jen v pohledu Studio).
- `components/StudioLane.tsx`: jedna cesta jako vodorovná dráha. Záhlaví: název, sdílený odznak ověření `domain-map/components/JourneyVerification.tsx` (logika `domain-map/logic/journey-verification.ts`) a proměna **A → B** (`pointA`, `pointB`). Zastávky = kroky (role, název stránky, `site.path`; menu jako „Menu“ / `nav`; chybějící stránka varovně). Klik na zastávku se stránkou → `onOpen` (Editor stránky).
- `components/StudioTransition.tsx`: přechod mezi zastávkami. Nad šipkou signál `via` jako věta (sdílené `stepSignal` z `domain-map/logic/journeys.ts` → `journey-via.ts`), odbočka u kroku s `after`; šipka obarvená stavem: **prošel** (`lastRun.passed && !stale`), **neprošel** (= `firstFailure` from/to, s důvodem), **ověření zastaralé** (`stale`), **neověřeno** (bez dokladu nebo přechod, který neprošlý doklad nedokazuje); pod ní realizace `line`, nebo štítek „nerealizováno“.
- `components/StudioFlows.tsx`: sloupec na druh toku (Navigace, Data, Příkaz, Událost, Neurčeno) s počtem vazeb a seznamem „zdroj → cíl“ seskupeným podle stránky zdroje. Klik: zdroj = stránka → `onOpen`, zdroj = komponenta → `onOpenFinding({kind: "node", id, pageId})`, tedy tentýž `openFinding` v `ArchitectureEditor` jako u Děr mapy (Editor stránky zdroje s vybraným zdrojem). Zdroj mimo stránky je jen text.
- `logic/studio-lanes.ts` (test vedle): `transitionState`, `studioLanes`, `TRANSITION_TEXT`.
- `logic/studio-flows.ts` (test vedle): `domainFlows(graph, domainId)` — vazby s oběma konci pod doménou, jen vazby `next` (`canCarry`, ostatní porty druh toku nenesou), popisky ze sdíleného `CARRIES_LABEL` (`shared/edge-carries/`), stránka zdroje podle předků (`lineage` z `map-check/logic/map-check.ts`).
- `styles/studio.css`, předpona `studio`. Barvy druhů toku jsou tokeny `--edge-carries-<druh>` z `design-tokens/styles/theme-tokens.css`, stejné jako čáry na plátně Editoru stránky.
