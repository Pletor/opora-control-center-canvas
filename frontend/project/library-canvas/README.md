# Plátno toku v knihovně (`library-canvas`)

Obrazovka jednoho plátna toku (kontrakt `docs/navrhy/2026-11-04-knihovna-platna-toku.md` §0 K2, §1, §2, §4). Otevírá se z panelu Komponenty nebo z odkazu u domény a stránky, v adrese `projectView=library&flow=<workflowId>` (vyřizuje App, `project/shell/logic/project-view.ts`).

- `components/LibraryCanvas.tsx` — rodič: drží data, zobrazenou verzi, neuloženou úpravu a zápis. Skládá hlavičku (titulek, místo prvku, rodokmen „vychází z <prvek>@<verze>“ s odkazem, upozornění na novější verzi v knihovně, počet odvozených), `library-versions/`, `library-actions/` a sdílený `shared/flow-editor/FlowEditor` v režimu plátna toku (`frames`: poznámky, rámce, inspektor polí uzlu; `nodePorts`; `checkErrors`).
- `command-bar/` — příkazový řádek (P1b): zadání textem se pošle srdci s kontextem plátna, lišta „Srdce kreslí…“ a načítání plátna do příchodu jeho draftu, který ukáže `ProposalBar`. Rodič mu dává jen `reload`, vybrané uzly (kliknutý uzel i uzly vybrané rámcem, `commandNodeIds`; editor je hlásí přes `onPick`) a callback `onWrote`.
- `element-context/` — plátno logiky prvku plátna 2 (`opora:project-flow:<nodeId>`, uzel s `element`, `docs/navrhy/2026-11-10-platno-2.md` verze 4): `use-element-context` načte graf prostoru (`/api/view`), `element-context.ts` (test vedle) z něj složí druh a název prvku, stránku › box a doménu a adresu návratu (`planRoute`: `domainId`, `pageId`, `architectureNode`, bez staré `editorId`). `ElementContextHead` je ukáže v hlavičce místo knihovny s **← Zpět na plán stránky**; adresu přepíše rodič a zavolá `onBack`. Editor, verze a příkazový řádek beze změny.
- `library-brief/` — dialog „Zadání pro agenta“ (P5): hotový text zadání karty z backendu (`GET /api/library/flows/{id}/brief`), Kopírovat a Zavřít. Tlačítko je v `library-actions/`.
- `logic/library-api.ts` — URL a volání `/api/library/*` a engine toků (verze, aktivace draft → candidate → active, návrat, `node-ports`, `graph-check`), slug z titulku, místo prvku z `owner_ref`. Test `library-api.test.ts`.
- `logic/node-ports.ts` — na co se ptát `POST /api/flow/node-ports`: porty uzlů dynamických typů a uzlů s chybovým výstupem, varianty typů z výčtových parametrů registru (paleta podle portu nabídne vektorové úložiště jako nástroj). Test `node-ports.test.ts`.
- `logic/use-library-flow.ts` — katalog s variantami (jednou za načtení stránky), detail plátna a detail zdroje rodokmenu. `logic/use-flow-checks.ts` — porty uzlů a kontrola grafu chvíli po úpravě.
- `logic/lineage.ts` — věty rodokmenu (použije je i `project/project-flows`) a původu plátna agenta `learnedFrom` („naučeno v projektu …“). Test `lineage.test.ts`.
- `styles/library-canvas.css`, předpona `library-canvas`.

Plátno se nespouští: místo „Připraveno ke spuštění“ editor ukáže pás kontroly grafu. Zápis do části Člověk smí jen člověk v UI, do části Agent i agent (pravidla hlídá backend). Výjimka K3: srdce smí do části Člověk uložit draft s poznámkou (návrh); přijme ho nebo zamítne jen člověk.
