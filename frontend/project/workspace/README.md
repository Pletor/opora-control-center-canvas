Pracovní plocha projektu: `ProjectWorkspace` skládá strom zadání aplikací a stránek, zachovaný strom skutečných souborů a mapu. Graf i operace vytvoření, úpravy a otevření stránky dostává z App; stránky mají stejná ID jako Editor. `WorkspaceSelection.sourcePath` zůstává cestou dokumentu, nikoli identitou stránky. Editor dokumentace k cestám dále používá `/api/workspace/document`.
