Pracovní plocha projektu: `ProjectWorkspace` skládá editor architektury, nebo strom skutečných souborů s mapou Graphify-out. `WorkspaceSelection.sourcePath` zůstává cestou dokumentu, nikoli identitou stránky. Editor architektury se klíčuje jen projektem (přepnutí worktree zachová otevřenou doménu a stránku); strom souborů projektem a prostorem.
