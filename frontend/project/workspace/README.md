Pracovní plocha projektu: `ProjectWorkspace` skládá editor architektury, Studio (`frontend/project/studio/`, klíčované projektem a prostorem; „Otevřít v Editoru stránky“ jde přes `onOpenArchitecture` do App), nebo strom skutečných souborů s mapou Graphify-out. `WorkspaceSelection.sourcePath` zůstává cestou dokumentu, nikoli identitou stránky. Editor architektury se klíčuje jen projektem (přepnutí worktree zachová otevřenou doménu a stránku); strom souborů projektem a prostorem.
