Pracovní plocha projektu: `ProjectWorkspace` skládá editor architektury (výchozí), Studio (`frontend/project/studio/`, klíčované projektem a prostorem; „Otevřít v Editoru stránky“ jde přes `onOpenArchitecture` do App), nebo plátno záměru stránky (`intent-canvas/`). Editor architektury se klíčuje jen projektem (přepnutí worktree zachová otevřenou doménu a stránku). Srdce sem nepatří, má vlastní obrazovku (`project/heart-screen/`).
