Kostra prostředí Projekt: `ProjectLayout` má v levém menu jen strom skutečných složek a souborů projektu (zrcadlo repozitáře) s hledáním a filtry cest; domény a stránky do něj nepatří. `ProjectMapNavigation` zachovává přepínání Architektura projektu / Graphify-out (místo po Archify zatím zůstává volné, přijde Studio, `docs/studio.md`). Plánované stránky se neprezentují jako prokázaný kód; zdrojové cesty a identity stránek zůstávají oddělené.

První volba `architecture` (Architektura projektu) vede v `ProjectWorkspace` přes přehled domén a mapu stránek do samostatného rychlého náčrtu. Podrobná práce se předává běžnému Editoru s konkrétním ID; náčrt nemá paralelní panel pracovního zadání. Graphify-out zůstává další volbou. Předchozí propojení této záložky s běžným plátnem v App je odstraněné; uložená data a identity stránek se tím nemění.
