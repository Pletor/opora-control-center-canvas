Kostra prostředí Projekt: `ProjectLayout` skládá zadání aplikací a stránek a strom skutečných zdrojů s původním hledáním a filtry cest. `ProjectMapNavigation` zachovává přepínání Archify / Graphify. Plánované stránky se neprezentují jako prokázaný kód; zdrojové cesty a identity stránek zůstávají oddělené.

První volba `architecture` (Architektura projektu) vede v `ProjectWorkspace` přes přehled domén a mapu stránek do samostatného rychlého náčrtu. Podrobná práce se předává běžnému Editoru s konkrétním ID; náčrt nemá paralelní panel pracovního zadání. Archify a Graphify-out zůstávají dalšími volbami. Předchozí propojení této záložky s běžným plátnem v App je odstraněné; uložená data a identity stránek se tím nemění.
