Krok 1, úvodní nastavení: seznam projektů, připojení repozitáře nebo složky, vytvoření projektu a jeho nastavení (ProjectHome); data z /api/projects.

V kartě Nastavení projektu stojí přepínač „Plná autonomie agentů“ a v hlavičce projektu štítek; stav i zápis drží App (`useAgentAutonomy`, prop `autonomy`), přepínač se ukládá hned a mimo revizi nastavení.

Pod cílem projektu stojí dílek `site-settings/` (nastavení a design webu, `settings.site`); ukládá se stejným tlačítkem a revizí jako ostatní nastavení.

Pod kartou nastavení stojí dílek `heart-pipeline/` „Pracovní workflow a pipeline srdce“: živý souhrn workflow srdce (aktivní verze, běhy, prostoje) a tlačítko „Otevřít canvas srdce“ na samostatnou obrazovku `screen=heart`.
