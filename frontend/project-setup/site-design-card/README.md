# Design systém webu (karta na stránce projektu)

Rozcestník pod pipeline srdce na stránce projektu (`ProjectHome`): věta, co design systém webu je, a tlačítko „Otevřít Správu webu“. Otevření (`projectView=site`, `frontend/project/site-admin/`) vyřizuje App přes `onOpen`; karta nic nenačítá ani neukládá.
