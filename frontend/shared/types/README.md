Sdílené TypeScript typy napříč frontendem (types.ts, workspace-mode.ts). `GraphEdge` nese vedle `port ∈ next | action | rule` i hodnotu `block` s nepovinnými `sourceBlockId` / `sourcePortId`; `EDGE_PORTS` zůstává seznamem portů na hraně karty, vazbu z tlačítka bloku pozná `isBlockEdge()` a její úchyt v React Flow sestaví `blockHandleId(blockId, portId)` do tvaru `block:<blockId>:<portId>`. `CanvasNode.blockOffsets` (`BlockOffsets`) drží místo odtažených bočních bloků Akce / Pravidla / Podklady jako posun `{ dx, dy }` proti kartě; chybějící port stojí na výchozím místě (`block-model`) a posun je relativní, takže karta bloky bere s sebou.
