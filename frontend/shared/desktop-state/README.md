Stav panelů sdílený Editorem a OporaHub (paměť projektu, workflow uzlu, podklady pro agenta): typy, klient /api/desktop-v3 a useDesktopState s CAS ochranou. Podle kontraktu `docs/karta-pro-agenty.md` nese stav navíc porty bloků (`Block.ports`, čtené přes `blockPorts()`), uzavření karty (`nodes[nodeId].done`, čtené přes `nodeWorkflowOf()`) a zprávy agenta na vazbách (`state.edges[edgeId]`, čtené přes `edgeReports()`). Všechna nová pole jsou při čtení nepovinná a dostávají výchozí hodnotu, aby starší uložený stav fungoval beze změny. Klient umí i `fetchNodeBrief` — jeden JSON s celou kartou pro model, jen ke čtení.

`fetchAgentWorkspaceSummaries` (typ `AgentWorkspaceSummaries`) načte jedním dotazem levný souhrn paměti všech karet — kolik z pěti polí je vyplněno, kdo psal naposled a kdy (`GET /api/desktop-v3/agent-workspace-summaries`). Stačí na hlavičky sbalených kapitol v módu Text; komunikace a ověření jsou jen v `fetchNodeBrief` (kontrakt `docs/souhrn-prace-agentu.md`).
