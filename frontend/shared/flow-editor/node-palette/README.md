# Paleta uzlů

`NodePalette` je pravý šuplík „Co bude dál?“: hledání a kategorie z registru (Spouštěče, Agent, Tok, Schválení, Sub-uzly podle kindu). Otevřená z „+“ u portu ukáže jen typy s kompatibilním portem. Klik hlásí `onPick(type)`, tah nese typ v `PALETTE_DRAG_TYPE`. Logika `logic/palette.ts` + test.
