# Paleta uzlů

`NodePalette` je pravý šuplík „Co bude dál?“: hledání a kategorie z registru (Spouštěče, Agent, Tok, Schválení, Sub-uzly podle kindu). Otevřená z „+“ u portu ukáže jen typy s kompatibilním portem. Klik hlásí `onPick(type)`, tah nese typ v `PALETTE_DRAG_TYPE`. Typy s `category` (katalog toků dat knihovny) se řadí do kategorií n8n (Spouštěče, AI, Akce, Transformace, Tok, Člověk) a AI do podkategorií podle výstupního sub-portu (Agent a řetězce, Modely, Paměť, Nástroje, Vektorová úložiště…). Filtr na port bere i varianty typu (porty pro jinou hodnotu parametru, např. vektorové úložiště jako nástroj); parametry varianty doplní editor při vložení (`variantFor` v `graph-edit.ts`). Logika `logic/palette.ts` + test.
