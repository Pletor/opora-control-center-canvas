Sdílené úchyty (porty) pro plátna React Flow: `components/PortHandle.tsx` obalí `Handle` (zásahová plocha 26 px, kulička 10 px, tabulátor, český `title` / `aria-label` / tooltip), `components/PortZoomVar.tsx` uvnitř `<ReactFlow>` zapisuje `--rf-inv-zoom` a `data-port-connecting` na kořen plátna přímo ze store (bez překreslení karet). `logic/port-labels.ts` (test vedle) drží názvy druhů portů (`next`, `action`, `rule`, `block`, `flow`, `material`, `pipeline`) a `inverseZoom` (omezený na 0,4 až 3, aby se sousední plochy nepřekrývaly). Styl `styles/flow-ports.css` (předpona `flow-port`); barvu volající dodá přes `--port-fill`, `--port-ring`, `--port-glow`, polohu přes `top`. Používá Editor (karta, blok, oblast) i stránka architektury.
