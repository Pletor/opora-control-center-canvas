Bloky u karty na plátně: `CanvasBlock` (rodič, typ React Flow uzlu `block`) ← `BlockFrame` (rám, úchyt, zavření) + `ActionsBlock` (pipeline v pořadí) / `RulesBlock` (musí / nesmí) / `MaterialsBlock` (obrázky nahrané do složky projektu, cesty ve zdroji, URL; přetažení nebo výběr souboru). Model a mutace v `logic/block-model.ts` (čistý, testovaný), styl ve `styles/blocks.css`. Bloky nejsou uzly grafu; data jsou v Desktop v3 `nodes[nodeId].actions` / `.rules` / `.materials`; nahrané soubory leží v `projects/<id>/canvas/materials/<uzel>/` (POST `/api/node-materials/upload`, GET `/api/node-materials/file`). Výběr pipeline řeší `../pipeline-picker`. Blok se dá odtáhnout po plátně za barevnou hlavičku (tělo nese `nodrag`): `blockOffsetOf` vrací buď uložený posun `blockOffsets[port]` uzlu grafu, nebo `defaultBlockOffset` u karty; Board rozebere id taženého bloku přes `parseBlockId` a nové `{ dx, dy }` proti pozici karty uloží App do `CanvasNode.blockOffsets`. Posun je relativní, takže karta si bloky při svém tahu bere s sebou.
