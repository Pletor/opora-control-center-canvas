Zpráva agenta na vazbě (inspektor vybrané čáry mezi kartami): `EdgeReportPanel` ukáže trasu zdroj → cíl, druh portu a u vazby z tlačítka bloku i číslo a název bloku s popiskem portu. Pod hlavičkou stojí pět pojmenovaných polí kontraktu `docs/karta-pro-agenty.md` — co se udělalo (log), souhrn výsledku, předání, zlepšení a chyby — a pod nimi podpis `updatedAt / by / agent` a tlačítko na smazání vazby. Panel nic neukládá: rozepsaný text drží u sebe, po opuštění pole ho ohlásí callbackem `onChange(field, value)` a rodič (App) ho zapíše přes `desktop.mutate(setEdgeReport(...))`. Když je main jen ke čtení nebo je stav Desktop v3 zamčený, pole jsou read-only. Čistý model v `logic/edge-report-model.ts` (`emptyReport`, `reportOf`, `setEdgeReport`, `edgeReportView`, `filledFields`, `reportSignature`) s testem vedle, styl v `styles/edge-report.css` v BEM.
