Karta uzlu na plátně, rozpadlá do dílků: `NodeCard` (rodič, skládá) ← `CardHead` (druh, fáze, u uzlu s kartou drobné štítky vrstvy (FE / BE / DB / Knihovna) a efektivního stavu — `node-card__badge`, `--ready`, `--done`; karta bez nich vypadá jako dřív — a u uzavřené karty zámek), `CardBody` (název s přejmenováním, podstata), `CardBlocks` (bloky obsahu v kartě: každý blok je rámeček s barevným pruhem podle stavu, hlavou — číslo / název / stav / nástroje přidat-posunout-přejmenovat-odebrat — a pod ní textarea s popisem bloku, ukládá se při odchodu z pole), `CardBlockPorts` (tlačítka bloku pod jeho rámečkem — každé nese popisek a na pravé hraně karty kuličku, což je zdrojový úchyt React Flow s id `block:<blockId>:<portId>`; „+ port“ přidá bez dialogu „Port N“, dvojklik port přejmenuje, nejvýš osm na blok), `CardFoot` (štítky, počty), `CardPorts` (čtyři kuličky: další krok / akce / pravidla / podklady; z podkladů se vazba netáhne). Blok vybraný na plátně (Board pozná klik na jeho plochu podle `data-block-id`) má zvýrazněný rámeček — `node-card__block--selected`; id vybraného bloku nese `NodeCardData.selectedBlockId`, jen pro kartu jeho vlastního uzlu. Karta s potvrzeným `done` má třídu `node-card--closed`: je ztlumená, v hlavě má zámek a bloky i porty jsou jen ke čtení. Přetahovat po plátně jde jen karta, proto všechno stisknutelné nese `nodrag`. Model v `logic/card-model.ts` (čistý, testovaný; `CardBlockRow` nese `text` i `ports`, `cardView` počítá `closed`, `doneProposed` a u uzlu `cardLayer` / `cardStatus` přes `cardLayer` / `effectiveStatus` ze `shared/card-context`), styl v `styles/node-card.css` v BEM s příběhovými komentáři (272 široká, nejméně 168 vysoká, zlatý řez; rytmus 13 / 8 / 5). Události bublají z dílků do rodiče a odtud do dat React Flow uzlu; dílek se dá upravit bez zásahu do ostatních.
