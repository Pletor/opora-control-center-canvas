# Aktivní milník ve Struktuře

Čte existující `GET /api/intake` pro projekt a pracovní prostor. Volba je místní pohled nad aktivními milníky, žádný další milník neukládá. Kritéria propojí prvky napříč větvemi; zvýrazní se reference, jejich potomci a cesta k nim. Ostatní karty zůstávají přístupné. Štítkový filtr je nezávislý.

Procento dokládá uzavření karet. Funkční splnění navíc vyžaduje kladné i záporné testy společné integrační karty, připnuté přijaté zadání, shodný běh a commit. Když backend tento doklad najde, pohled uvede „Integrační scénář doložen Kanceláří“; jde o hlášení pracovníka s ověřenými vazbami, nikoliv nezávislé spuštění testů. Přijetí prototypu nebo samotné uzavření karty funkční zkoušku nedokládá.
