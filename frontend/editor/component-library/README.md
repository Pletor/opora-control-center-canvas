`library-catalog/` drží praktické předlohy Frontendu, Backendu, Databáze a Infrastruktury a převod na dávku `canvas-plan`; zobrazuje je katalog v prostředí Projekt (`project/architecture-editor/page-editor/`). Editor sekci Knihovna nemá (menu Editoru je Struktura · Schránka · Nastavení, `layout/panel-dock/`); strom vložených částí je sekce Struktura (`layout/structure-panel/`). Katalog Agentů a postupů (`agent-catalog/`) byl smazán spolu se sekcemi Agenti a Postupy. `node-library/` drží už jen styly obalu bočního menu bloku (`BlockPanelDrawer`). `palette/` je starý nevyužitý slot, nikoli další katalog.
