Knihovna uzlu (levá hrana plátna Editoru): `NodeLibraryDrawer` vyjede po kliknutí na kartu a zajede, když výběr zmizí; žádná pevná lišta. V hlavě jsou záložky Bloky / Akce / Podklady / Kontext (`LibraryContext` = co model dostane a co chybí). Sekce Podklady používá `workflow/blocks/components/MaterialsBlock` (stejný dílek jako blok u karty). Sekce Kontext hlídá sedm věcí — cíl, zadání v blocích, hranice, kritéria, podklady, postup a nově „Porty a vazby“ (splněno, když z některého portu bloku vede vazba `port: "block"` na jinou kartu; graf jde do `contextChecks` jako parametr) — a nabízí tlačítko „Stáhnout balíček pro model“, které přečte `GET /api/desktop-v3/node-brief` a ukáže JSON v `<pre>` s kopírováním. Stažení je jediné volání API v tomto dílku a je jen čtení; nic se tím modelu neodesílá. Model v `logic/library-model.ts` (stav panelu, druhy bloků `addBlockOfKind`, kontrola kontextu `contextChecks`, `linkedBlockPorts`), test vedle něj. Styl `styles/node-library.css` v BEM (`node-library__tab--active`). Panel nic neukládá: přidání bloku, akce či podkladu bublá do App, který drží `useDesktopState`; u uzavřené karty (`done.confirmed`) přichází panel jen ke čtení.
