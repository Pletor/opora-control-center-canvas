Předat zadání z Editoru načítá uložený `node-brief`, ukazuje cíl a mezery a kopíruje/stahuje úplný JSON včetně `contextVersion` a kontraktu výsledku. Vybraný text je pouze orientační; nenahrazuje uložené zadání. `ResultSubmission` přijímá celý výstupní požadavek s původní verzí, při chybě zachovává text a ověřuje uloženou identitu výsledku zpětným GET. `ResultHistory` ukazuje hlášení a jejich původní zadání v záložce Práce. Nic samo nespouští model. Typ `AgentTaskRequest` (scope předání) leží v `TaskHandoff.tsx`.
