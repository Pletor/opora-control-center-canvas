Detail uzlu v Editoru: NodePanel skládá hlavičku, záložky (`NodeTabs`: Obsah, Strom, Zadání, Proces), tělo a patičku, vedle něj vrstva LayerContext (deník + odkazy). Podsložky: card-fields (karta uzlu v záložce Zadání: vrstva jako čipy FE · BE · DB · Knihovna, stav, model, effort, termín — tatáž pole jako pop-up tvorby; „Uložit kartu“ jde přes `onSave` jako podstata), content, tree (strom obsahu: očíslované bloky s porty, štítky, TODO, obrázky, stav s větvením), assignment, process, done (uzavření karty: stav `done`, poznámka, „Uzavřít kartu“ / „Znovu otevřít“; potvrzuje člověk, agent smí jen navrhnout), journal, links, ideas (záložka Podněty: ne-blokující nálezy review a kritiků, odškrtává člověk), brief-vault (sdílený model a strom schránky zadání; v detailu karty jen čipy „Ze schránky“ v záložce Zadání, odznak „zadání se změnilo“ a u sektoru či karty s vlastní schránkou tlačítko „Otevřít ve Schránce“ — Schránka sama žije v levém menu Editoru, `frontend/editor/brief-vault-dock/`). Panel ani dílky nic neukládají; každá změna bublá do App, který drží `useDesktopState`, zámek a revizi.

`agent-summary/` je souhrn práce agentů nad kapitolami módu Text: tabulka jen pro rozbalené karty (stav, paměť, komunikace, ověření, další krok) a fronta briefů po jednom (`docs/souhrn-prace-agentu.md`); skládá ho `content/TextWorkspace`.
