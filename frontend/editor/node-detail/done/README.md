Uzavření karty (záložka Proces v detailu uzlu): `DoneControl` ukáže stav `done` z Desktop v3 stavu — `otevřeno`, `navrženo agentem` (když `by: "agent"` a `confirmed: false`) nebo `uzavřeno` s razítkem času —, nabídne poznámku a dvě tlačítka „Uzavřít kartu“ / „Znovu otevřít“. Podle kontraktu `docs/karta-pro-agenty.md` smí agent uzavření jen navrhnout; `confirmed: true` zapisuje člověk. Dílek nic neukládá: rozhodnutí bublá nahoru callbackem `onDone(patch)` a rodič (App) ho zapíše přes `desktop.mutate(setDone(nodeId, patch))` z `node-detail/tree/logic/tree-model.ts`. Uzavřená karta má pak na plátně i v knihovně bloky, porty a podklady jen ke čtení a je ztlumená se zámkem. Styl `styles/done-control.css` v BEM.
