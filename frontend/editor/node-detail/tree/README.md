Záložka Strom v detailu uzlu: `NodeTree` (rodič: stav Desktop v3, zámek zápisu, rozbalení) ← `TreeBlock` (jeden blok) ← `BlockTags`, `BlockTodos`, `BlockImages`, `BlockState` (dílky, jen události nahoru). Model v `logic/tree-model.ts`: číslování 1 / 1.1 / 1.2, přesuny, větve „splněno → / nesplněno →“ na existující ID, porty bloku (`addBlockPort`, `renameBlockPort`, `removeBlockPort`: nejvýš osm na blok, unikátní ID, popisek do 80 znaků) a uzavření karty (`setDone`, které razítkuje čas a drží podpis `human` / `agent`), vše testováno. Styl `styles/tree.css`. Data: `nodes[nodeId].blocks` a `nodes[nodeId].done` ve stavu Desktop v3; dohledání ID přes `/api/desktop-v3/trace`.
