# card-inspector — inspektor karty Živého procesu

Pro vybraný řádek mapy: kdo je na tahu (člověk, když poslední událost čeká na něj), odkazy z nejnovější
události, která je nese (běh, větev, PR jen jako https odkaz zdroje, commit, patro), kontroly z fáze Kontroly
a časová osa karty. Tlačítko „Otevřít detail karty“ hlásí `onOpenCard`; rodič otevře jednotný drawer karty.
Model `logic/inspector-model.ts` (test vedle).
