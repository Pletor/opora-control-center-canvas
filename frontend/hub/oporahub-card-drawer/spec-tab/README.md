# Záložka Zadání

Přijaté proti pracovnímu zadání karty (cíl, ne-cíle, akceptace po řádcích, kroky po ID) z `GET /api/oporahub/changesets/context`, čekající návrhy s rizikem z `…/proposal-reviews` a odeslání pracovních změn jako návrhu (`POST /api/oporahub/changesets`). Ponechané editory (pracovní zadání `NodeSpecEditor` s účelem komponenty, Schránka, popis, nastavení karty, vazby) jsou ve sbalených oddílech. Logika rozdílu: `logic/spec-diff.ts` (test vedle).
