# Pohled pro agenty

Záložka „Pro agenty“: protokol, hlavy pro CAS (`data-oh-field`), fronta akcí (`data-oh-action-id`, `data-oh-action-status`, metoda, cesta, preconditions), přesný JSON ke zkopírování a tabulka kontraktu `logic/contract.ts` (test `contract.test.ts`). Pohled nic nezapisuje; akce `human_only` zůstávají jen pro člověka.
