Nastavení aplikace otevírané z levého dolního rohu (SettingsDialog), jediné místo pro nastavení: Obecné = vzhled; Plátno = mřížka a přichytávání; Projekt = nastavení, obnova, synchronizace mainu, odebrání repozitáře; Skills = katalog skills Claude Code s možností vypnout (/api/claude-code/skills); Connectors = katalog aplikací k napojení.
