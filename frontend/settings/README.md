Nastavení aplikace otevírané z levého dolního rohu (SettingsDialog), jediné místo pro nastavení: Obecné = vzhled a globální přepínač „Automatická aktualizace map po mergi do main“ (`GET /api/map-refresh/config`, `POST /api/map-refresh/configure`; řádek `MapRefreshSetting`, pravidla v `logic/map-refresh-config.ts` s testem; ukládá `GeneralSection`, platí pro celou aplikaci, viz `docs/mapy-projektu.md`); Plátno = mřížka a přichytávání; Projekt = nastavení, obnova, synchronizace mainu, odebrání repozitáře; Skills = katalog skills Claude Code s možností vypnout (/api/claude-code/skills); Connectors = katalog aplikací k napojení.

Connectors: většina položek je zatím jen katalog (`status: "planned"`). **OpenViking – paměť rolí** je živý (`status: "live"`): stav se čte z `GET /api/memory/status` a tlačítko volá `POST /api/memory/settings` a hned potom stav načte znovu, takže se v seznamu ukazuje odpověď serveru, ne přání klienta — zapnutá paměť s nespuštěným serverem je „Nedostupné“, ne „K dispozici“. Server žijící bez klíčů rolí je „Vyžaduje založení rolí“ (`needs_provisioning`): tlačítko „Založit klíče rolí“ pošle `POST /api/memory/provision {confirmed: true}`, ukáže výsledek (založeno / beze změny / chyby) a hned poté přečte stav znovu — klíč sám se v odpovědi nikdy neobjeví. Přepínač platí pro celou aplikaci, nikdy pro jeden projekt (`docs/pamet-agentu.md`, `docs/pravidla-struktury.md`). Pravidla pohledu jsou čistá v `logic/connectors.ts` (`memoryConnector`, `memorySettingsPayload`, `provisionPayload`, `provisionResultSummary`) s testem vedle.

Asistent: textarea „Pokyny asistenta“ (systémový prompt, `GET`/`POST /api/assistant/instructions`, `text: null` obnoví výchozí, limit 12 000 znaků). `AssistantSection` načte pokyny při otevření, drží rozepsaný text, ukládá a po uložení znovu čte server; pole a tlačítka jsou dílek `AssistantInstructionsSetting`, pravidla (`parseAssistantInstructions`, `instructionsPayload`, `instructionsView`) v `logic/assistant-instructions.ts` s testem. Platí pro celou aplikaci a projeví se v nově spuštěné session (`docs/asistent.md` §14.1). Pod pokyny je „Klíč Jev“ (`JevKeySetting`, sám čte `GET /api/assistant/status` a zapisuje `POST /api/assistant/jev-key {key | null, provider}`): pro každého poskytovatele maskované pole, Uložit a Smazat, stav jen „nastavený / nenastavený“; klíč se po uložení z pole smaže a server ho nikdy nevrací. Pravidla (`parseJevStatus`, `jevKeyHint`, `jevKeyPayload`, `jevKeyRows`) v `logic/jev-key.ts` s testem (`docs/asistent.md` §13.2).
