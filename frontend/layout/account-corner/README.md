Levý dolní roh aplikace: tlačítko Opora a jeho popup menu (AccountCorner). Dnes jediná položka Nastavení; jazyk, nápověda a účet přibudou postupně.

Tlačítko plave nad všemi obrazovkami, proto je v klidu jen kulatá značka (36 px) a nápis „Opora“ se vysune při najetí, fokusu nebo otevřeném menu. Posouvací plochy mu dávají rezervu tokeny `--account-corner-safe` (dole) a `--account-corner-gutter` (vlevo) z `design-tokens/styles/theme-tokens.css`; nová obrazovka s obsahem až k levému dolnímu rohu je má použít místo vlastních čísel.
